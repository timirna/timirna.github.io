Worth trying. Your site uses the SVG renderer, which draws every shape as a separate element in the page. How to read it

Average above 50 is smooth. 30 to 50 is visibly uneven. Below 30 is the stutter you have been seeing. “Stutters” counts frames that took longer than 1/30th of a second — those are the ones the eye catches. The full versions get heavier about halfway through, so let a test run the whole twenty seconds rather than judging the opening.
