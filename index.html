From one reference to a living character.

Koala Sleep Tracker is a character-led sleep companion app for iOS. Instead of dry charts, it expresses your sleep through a koala that reacts to how you sleep.

CLIENTDeveloper of Koala Sleep Tracker (iOS)
MY ROLECharacter design, rigging, animation
TOOLSAdobe Illustrator, Rive
DELIVERABLEOne lightweight .riv file
01 — Challenge

Not decoration — the experience

The developer came with a single reference image and a vision: the koala should be the app experience. That meant a wide emotional range, smooth transitions between moods, and a file light enough to run in real time on mobile. Pre-rendered video was never an option.

02 — Design

Flat vector, built for rigging

In Illustrator I developed the reference into a full master illustration as clean flat vector — tiny files, perfect scaling, and every limb, ear, eyelid and facial feature built as a separate animation-ready piece. Shadows and colour detailing were done inside Rive so depth moves with the character.

03 — Rig & state machine

One artboard, one brain

Rigged with bones and constraints, then animated nine states. They first lived across several artboards; I consolidated them into one unified state machine, so the koala flows between any mood the app calls for with no duplicated assets.

Master illustration — flat vector built with rigging in mind.
